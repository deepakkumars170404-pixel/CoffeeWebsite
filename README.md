# DK CAFENA - Coffee Shop Website ☕︎

A responsive multi-page website for a coffee shop named **DK CAFENA**, built with HTML, CSS, and Bootstrap.

## 🌟 Features
- **Home:** Welcoming landing page with easy navigation to the menu and order section.
- **Products:** Browse our selection of coffee products.
- **Menu:** Explore our variety of handcrafted coffee drinks (Americano, Cappuccino, Mocha, Cold Coffee, etc.).
- **Locations:** Find a DK CAFENA store near you.
- **Contact:** Get in touch with us for any queries.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Custom styling via `cafe.css`)
- **Bootstrap 5** (For responsive navigation and layout)

## 🚀 Getting Started
To view this project locally:
1. Clone or download the repository.
2. Open `index.html` in your favorite web browser.
